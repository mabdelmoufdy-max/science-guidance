## ما اختُبر وما لم يُختبر
- ✅ الدورة كاملة (قبل/تطبيق/تطبيق مكرر مرفوض/بعد/رجوع/قبل/تطبيق/بعد/رجوع) على **Postgres 16 محلي بقاعدة بديلة مبسّطة** تحاكي العرض والدالة والسياسات بنفس النصوص.
- ✅ اختبارات الطفرة: الإصلاح ذو الطرف الواحد ← `FAIL 2a`؛ ترك lookup بلا قائمة أدوار ← `FAIL 1d`؛ سياسة تدقيق مفتوحة ← `FAIL 4a`؛ بلا إصلاح ← `FAIL 1a`.
- ❌ **لم يُختبر على نسخة من القاعدة الحقيقية**: نص `pg_get_viewdef` الحقيقي (Postgres 17) قد يختلف فيتوقف الإصلاح بأمان؛ ونص `lookup_identity_by_civil` الحقيقي (موضع `begin`)؛ والأعمدة الإلزامية في الجداول الحقيقية لبيانات الاختبار؛ ومنطق `current_app_role` الحقيقي (البديل يحاكي: الترويسة إن كان الدور نشطًا وإلا الدور الوحيد).
